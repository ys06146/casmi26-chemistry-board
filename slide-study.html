1. From MS/MS to 25 ranked structures

For each compound, submit up to 25 candidate structures and put the correct one near the front.

MS/MS spectrum
A set of fragment-ion signals. Peak position is m/z; height is relative intensity.
Top-25 versus MRR@25
Top-25 asks whether the answer is in the list. MRR also rewards placing it earlier.

Likely question
Are we ranking 25 different compounds against each other?

No. Each unknown compound gets its own list of up to 25 proposed structures.

Limits of the claim
A high-ranked or generated candidate is a hypothesis, not an experimental structure confirmation.

Read the speaker script

Our task is to infer a molecular structure from its tandem mass spectrum. MS/MS measures the mass-to-charge ratios and intensities of ions produced when a selected precursor fragments. We use multiple observations together when they belong to the same compound. For every compound, we submit a separate list of up to 25 candidate structures. We need both good coverage and good ordering: having the correct answer somewhere in the list is not enough. Our metric, MRR at 25, gives a score of one for rank one, one-half for rank two, and one twenty-fifth for rank 25. It gives zero when the answer is outside that range. We then average across compounds. This is why the project combines ways to obtain candidates with ways to rank them.

2. Four models, two branches, one ranked list

Retrieve and generate candidates, check predicted spectra, then combine the result with reference-spectrum search.

MIST
Spectrum → predicted fingerprint → score or retrieve existing structure candidates. MIST is not the structure generator here.
FRIGID-base and ICEBERG
FRIGID-base proposes structures; ICEBERG checks them by predicting their spectra.
DreaMS and RRF
DreaMS supports reference-spectrum search. RRF combines ranks using terms like w/(10+r); its score is not a probability.

Likely question
Does a 100-candidate pool mean the submission contains 100 structures?

No. A larger pool supports reranking; the final submission remains capped at 25 structures per compound.

Limits of the claim
The figure omits fallback paths. Do not describe the full published FRIGID correction procedure as already implemented.

Read the speaker script

MIST predicts a molecular fingerprint from the observed spectrum. Think of that fingerprint as a set of structural features. It helps retrieve matching structures from a catalog. FRIGID-base uses the fingerprint and a selected molecular formula to generate more candidate structures. ICEBERG then runs the problem in the other direction: it predicts a spectrum for each candidate structure and compares that prediction with the observation. The result is combined with the base ranking. The lower branch uses the public DreaMS model for direct and analog reference-spectrum search, producing another structure ranking. Finally, reciprocal rank fusion combines the two branches. Earlier candidates contribute more, and the weights control each branch’s influence. We evaluate up to 100 candidates but submit at most 25. These are different limits. This diagram describes our actual implementation: FRIGID-base generation, without the full iterative correction loop. It also uses the public DreaMS search path rather than the team’s separate private ensemble.

3. Our best recorded public score is 0.265

The v3 ensemble is the current reference; the later v4 setting change reduced the recorded score.

Public score
A competition evaluation result; it is distinct from our RIKEN or NP development metrics.
Ablation
Change one factor, or use a factorial design, so its effect can be separated from other changes.
Output parity
A faster implementation produces the same reference output. Speed alone does not improve accuracy.

Likely question
Does a bigger model weight reliably improve performance?

No. Weighting changes which ranking signals win. It can help one set and hurt another.

Limits of the claim
These scores are a dated experiment record, not a claim about the current leaderboard or a newly run submission.

Read the speaker script

These are completed public competition scores recorded through November first. The MIST submission scored 0.232. Adding FRIGID-base reached 0.233. ICEBERG reranking of 25 candidates reached 0.239, and expanding that reranking pool to 100 reached 0.260. Adding the DreaMS rank ensemble in v3 produced our best recorded score, 0.265. The later v4 adjustment fell to 0.257. In that adjustment we increased the DreaMS weight, reduced the ICEBERG weight, and expanded the depth used in final fusion. Because three settings changed together, this comparison does not isolate which change caused the overall decrease. We should preserve v3 as the reference and separate those effects. We also made an independent engineering improvement: GPU caching reduced the observed full-run time from about 118.3 to 108.7 minutes while preserving the reference output. That is a speed result, not a new accuracy result. These timings came from different runs, not a repeated controlled benchmark.

4. The answer was present, but its rank got worse

In RIKEN, 11 correct first-place results fell behind even though all 11 remained in the top 25.

Coverage versus ranking
Coverage asks whether the right structure is available. Ranking asks where it lands among the available candidates.
Evaluation-equivalent group
Tautomer normalization can map several representations to the same scored identity. Best ranks in different branches may belong to different raw entries.

Likely question
Should we generate more structures to fix these 11 cases?

The correct structures are already available. Start by improving ranking; revisit generation when missing candidates are the limiting factor.

Limits of the claim
RIKEN is separate from the hidden competition inputs. After analyzing it, treat it as development data. Pretraining overlap has not been ruled out.

Read the speaker script

In the 100-structure RIKEN comparison, v3 put 51 correct structures first. Eleven of those lost first place in v4, while six other cases improved to first place. That leaves 46 correct first-place results. Meanwhile, the number of compounds with a correct answer anywhere in the first 25 rose slightly, from 86 to 87. All eleven regressions still had their correct answer between ranks two and six. So our first priority for these cases is better ordering of available candidates. In confirm0003, the correct structure fell from first to second. ICEBERG strongly supported the correct candidate, and replaying the saved scores reproduced a reversal when its fusion weight decreased. We also found three representations that share one evaluation identity but entered ranking separately. The chemistry guide compares the structures and explains a possible fragment at m/z 84.081. That fragment assignment remains a hypothesis. The exact rank replay is verified for this case; it is not a complete explanation for all eleven.

5. Next: separate weights, normalize groups, test chemistry

Test the suspected ranking failure before adding generation cost.

2 × 2 × 2 design
Eight combinations separate two settings for each of three factors and can expose interactions.
Grouping before fusion
Use the same identity rule as evaluation, but avoid rewarding a structure simply because it has more duplicate representations.
Chemical support score
A computable feature expressing limited evidence. Its benefit must be measured, and its failure cases documented.

Likely question
Why not delete every candidate that fails the proposed fragment rule?

Fragmentation depends on conditions, and different structures can produce the same ion. Begin with a soft contribution and test counterexamples.

Limits of the claim
The eight-way comparison, grouping change, and chemical score are future experiments, not completed gains.

Read the speaker script

The first experiment separates the three changes using the saved scores. Two DreaMS weights, two ICEBERG weights, and two fusion depths give eight combinations. Holding the candidate pool fixed lets us compare these settings without regenerating everything. The second experiment aligns grouping with the evaluator. We would combine equivalent tautomer representations before fusion, taking one representative rank per branch rather than adding duplicate contributions. This needs a controlled comparison, because the best grouping rule is not established. The third experiment translates chemical interpretation into a small support score. For example, does a candidate have the terminal structural motif that could explain the 84.081 peak? We need to check other possible origins, collision conditions, and counterexamples before relying on that clue. The feature must use the observed spectrum and candidate structure, not the known answer. We would first test a modest bonus, not remove candidates on a weak rule. None of these three proposed changes has yet demonstrated an improvement.

6. Confirm on new molecules before submitting again

Develop on existing cases, freeze the settings, confirm the gain independently, then adopt it.

Development versus confirmation
Data used to choose settings are development data. Fresh confirmation tests whether the chosen improvement transfers.
Molecule-level split
Keep spectra of one molecule together so similar observations do not appear on both sides of the split.
Freeze before evaluation
Set the method, success criterion, and cost limit before seeing confirmation results.

Likely question
Why not keep tuning directly on RIKEN until the score rises?

That would adapt the method to cases we already know. It would not establish generalization to new molecules.

Limits of the claim
The six improved cases are useful counterexamples, but do not replace a full held-out evaluation. A submission is planned, not already made.

Read the speaker script

We will use the NP and RIKEN material already inspected to develop candidate improvements. Before confirmation, we need to freeze the settings, choose a minimum useful improvement, and decide how much extra runtime is acceptable. We then evaluate on a separate set of molecules. Molecule-level separation matters because several spectra can belong to the same compound. The main metric remains MRR at 25, alongside first-place accuracy, top-25 coverage, subgroup behavior, and runtime. We keep the v3 configuration and its 0.265 submission as the reference. The chemistry reviewer will work through the eleven regressions and six improved comparison cases, recording structural differences, peak evidence, uncertainty, and counterexamples. The model developer will replay scores, implement one feature at a time, and compare against the preserved baseline. We adopt a change only if it meets the criteria on the separate confirmation set. Then we submit and record the exact configuration and result.
